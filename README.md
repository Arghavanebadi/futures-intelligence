# Futures Intelligence

داشبورد پژوهشی فارسی برای پایش تعدادی قرارداد دائمی USDT؛ Bybit از API عمومی مستقیم استفاده می‌کند و سایر صرافی‌ها به CCXT نیاز دارند. برنامه در پس‌زمینه و تا زمانی که روشن باشد، داده عمومی بازار را به‌صورت دوره‌ای دریافت و ارزیابی می‌کند.

**این نسخه سیگنال پژوهشی تولید می‌کند و هیچ سفارش واقعی، سفارش محافظ، احراز هویت حساب یا معامله خودکاری انجام نمی‌دهد. برای استفاده در فیوچرز با پول واقعی یا فروش به‌عنوان سیستم سودآور آماده نیست.**

## نصب و اجرا در ویندوز

Python 3.10 یا جدیدتر:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe app.py
```

`http://127.0.0.1:8765` را در مرورگر باز کنید. برای توقف `Ctrl+C` را بزنید. به‌روزرسانی خودکار صفحه هر ۱۵ ثانیه و دریافت دوره‌ای بازار به طور پیش‌فرض هر ۵ دقیقه است. برنامه از داده ساختگی استفاده نمی‌کند. در صورت قطع دسترسی، خطا نشان داده می‌شود و داده قدیمی به عنوان فرصت منتخب نشان داده نمی‌شود.

## تنظیم صرافی و نمادها

پیش‌فرض Bybit و سه بازار BTC، ETH و SOL است و برای آن نصب وابستگی لازم نیست. برای سایر صرافی‌های سازگار ابتدا `python -m pip install -r requirements.txt` را اجرا کنید. امکان دسترسی به داده عمومی، نام نمادها، قابلیت‌ها و محدودیت‌ها به صرافی و منطقه بستگی دارد. مثال PowerShell:

```powershell
$env:EXCHANGE_ID="bybit"
$env:FUTURES_SYMBOLS="BTC/USDT:USDT,ETH/USDT:USDT,SOL/USDT:USDT"
$env:SCAN_INTERVAL_SECONDS="300"
$env:PORT="8765"
.\.venv\Scripts\python.exe app.py
```

حداکثر ۲۰ نماد و حداقل فاصله اسکن ۶۰ ثانیه است. فقط قراردادهای دائمی خطی تسویه‌شونده با USDT پشتیبانی می‌شوند؛ سازگاری همه صرافی‌ها تضمین نشده است. درخواست به صرافی‌ها ممکن است با خطای محدودیت، منطقه یا شبکه مواجه شود.

## نحوه تحلیل

از داده OHLCV یک‌ساعته استفاده می‌شود؛ کندل باز، داده نامعتبر، قدیمی یا با فاصله زمانی نامنظم رد می‌شود. ۱۵ نقش در پنل نمایشی وجود دارند که چند نقش آن‌ها محاسبات محلی EMA، RSI، ATR، شکست، حجم و بازده را انجام می‌دهند. این‌ها ۱۵ مدل هوش مصنوعی مستقل نیستند. ۱۵ نقش، تحلیل‌گرهای محاسباتی مبتنی بر کندل و حجم هستند و مدل Grok یا ایجنت‌های هوش مصنوعی مستقل نیستند. اخبار، دفتر سفارش و اطلاعات قابل اتکای نهنگ‌ها متصل نیستند و نباید به عنوان داده موجود تلقی شوند. Funding و open interest فقط در صورت پشتیبانی و دریافت موفق نمایش داده می‌شوند و در رأی سیگنال دخالت ندارند.

رأی تکنیکال مثبت حداقل سه نقش و جمع رأی حداقل ۳ به همراه فیلتر ATR حداکثر ۳٪، وضعیت LONG پژوهشی می‌دهد؛ رأی منفی حداقل سه نقش، جمع رأی حداکثر منفی ۳ و ATR حداکثر ۳٪ وضعیت SHORT پژوهشی می‌دهد. در غیر این صورت WAIT است. از بین موارد غیر WAIT، قدر مطلق جمع رأی انتخاب می‌شود. حد مرجع LONG دو ATR پایین‌تر و هدف سه ATR بالاتر است؛ برای SHORT برعکس است. این سطوح سفارش محافظ نیستند. تحلیل از قیمت آخرین کندل بسته استفاده می‌کند، نه قیمت لحظه‌ای اجرای سفارش. رأی و انتخاب به معنی احتمال موفقیت یا تضمین سود نیست.

## پایش ۲۴ ساعته

برنامه فقط زمانی پایش می‌کند که پردازش Python و دستگاه روشن باشند و شبکه و صرافی پاسخ دهند. بعد از راه‌اندازی مجدد سرور دوباره شروع می‌شود. این نسخه سرویس نصب‌شده، ناظر پردازش، اعلان قطع، بازیابی تاریخچه یا تضمین دسترس‌پذیری ۲۴ ساعته ندارد. برای استفاده دائمی باید به‌طور مستقل میزبانی، راه‌اندازی خودکار و پایش سلامت تنظیم شوند. سرور فقط localhost است و نباید بدون طراحی امنیتی در اینترنت منتشر شود.

## تست

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

تست‌ها از داده و صرافی شبیه‌سازی‌شده برای اعتبارسنجی نرم‌افزار استفاده می‌کنند؛ بک‌تست مستقل، forward test، داده نهنگ، تحلیل بنیادی یا آزمون سودآوری واقعی انجام نشده است. خروجی گزارش JSON از دکمه دانلود داشبورد قابل دریافت است.

## گزارش فعالیت نقش‌ها

صفحه وضعیت هر ۱۵ نقش، پیشرفت اسکن و ۱۰۰ رویداد اخیر همین اجرای برنامه را نشان می‌دهد؛ گزارش فعالیت در حافظه است و پس از راه‌اندازی مجدد پاک می‌شود. در صورت قطع اتصال، نقش‌ها «بدون داده» نشان داده می‌شوند؛ نتایج قدیمی قابل انتخاب نیستند. داده funding و بهره باز، در صورت دریافت، در پنل کیفیت داده نمایش داده می‌شود و رأی سیگنال را تغییر نمی‌دهد. با انتخاب نماد و زدن دکمه تحلیل، بررسی مجدد درخواست می‌شود. برنامه خودآموز نیست و پارامترها را به‌طور خودکار تغییر نمی‌دهد. برای ارزیابی بهبود لازم است داده تاریخی و آزمون مستقل طراحی و اجرا شود.
